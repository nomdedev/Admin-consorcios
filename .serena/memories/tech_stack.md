Tech stack:
- Frontend: Next.js 14 (App Router), React 18, TanStack Query, Zustand, React Hook Form, Zod.
- UI: Radix UI + Tailwind CSS + CVA; accessibility focus (WCAG 2.1 AA), touch targets 44x44px.
- Backend: NestJS (TypeScript), Prisma ORM, PostgreSQL (Neon), JWT auth, Throttler.
- Infra: Vercel (frontend), Railway (backend), Resend (email), Supabase storage.
- Tooling: Turborepo, npm workspaces, Vitest/RTL for frontend tests, Jest/Supertest for API tests, Playwright for admin-web e2e.
Refs: docs/architecture/ARCH-002-tech-stack.md, PROJECT-README.md.
